# Student Grade Calculator

## Description
This project aims to inform students about their potential grade by allowing them to input essential subject information, then calculating their general weighted average (GWA) across all quarters. This program is tailored for Philippine Science High School System students and aligns with the institution's grading system to maximize time management, organization, and ease of use compared to other spreadsheet tools.

## Installation Requirements
- Windows 10 (due to directory issues)
- Python version 3+
- The *Flask* library should be installed before running the application. You can run 'pip install flask' in your terminal to download this package.

## Usage
Run the executable Python code and open localhost:5000 in your preferred browser.
