# Student Grade Calculator

## About
This project aims to inform the student about their potential grade.

## Objectives
Be able to show tentative grade.
Inform student about their grade.

## Features

## Program Requirements
- Windows 10 (due to directory issues)
- Python version 3+
- The *Flask* library is required to be installed before running the application. You can run 'pip install flask' in your terminal to download this package.

## How to Run
Run the executable python code and open localhost:5000 in your preffered browser.
